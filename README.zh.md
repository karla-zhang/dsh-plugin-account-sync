# Account Sync 账户同步

[English](README.md)

一个 DeepSeek Harness 插件：让**同一账号下的不同终端**保持同步——已安装的插件及启用状态、应用设置、选定的工作区文件、会话记录、技能与 Agent 预设。

DSH 目前没有服务端的账号级存储（会话只会单向随推理请求上传），所以本插件通过你自己掌控的传输通道同步。内置四种**可选项**：

| 传输方式 | 需要什么 | 适合场景 |
| --- | --- | --- |
| **文件夹 Folder** | 两台机器都能访问的共享文件夹（百度网盘 / OneDrive / Syncthing / 网络共享） | 最简单，由网盘客户端负责搬运 |
| **Git** | 两台机器都能访问的 git 远端 | 有历史、可审计差异、冲突可手工处理 |
| **WebDAV** | 任意 WebDAV 服务（坚果云、Nextcloud、NAS…） | 两台机器很少同时在线 |
| **局域网 LAN** | 一台机器做 host 监听端口，另一台连接 | 无云账号、局域网内快速同步 |

每个内容分类都有独立开关；真正同步前可以先点**预览 Plan** 看会做什么。

## 安装

1. 打开 **设置 → 插件**，从本地目录安装本 bundle（`plugin_manager` 的 `install_bundle` 指向本目录），或使用插件页的"从文件夹安装"。
2. 若 DSH 提示需要重启，重启后打开 **设置 → Account Sync / 账户同步**。
3. 选择传输方式并填写参数，点**测试**，再点**立即同步**（可先点**预览**）。
4. 需要自动同步时打开 `autoSync` 定时器。

跨设备布局：每台设备发布到 `<root>/devices/<deviceId>/`，各设备只读取其它设备的目录，任何两台设备都不会写同一个文件。删除永不传播；会话日志只在本地缺失时导入（只追加的日志从不覆盖）；工作区/技能文件冲突时保留双方（`文件名.sync-conflict-<对端>-<时间戳>.扩展名`）。

**局域网配对**：host 机器把角色设为 `host`，点**测试**后复制显示的配对信息（`配对信息 / pairing · http://<局域网IP>:47810/_account-sync · token: …`）。令牌保存在凭据库中，仅通过该同源测试请求显示；client 机器把角色设为 `client`，粘贴地址与令牌，点**测试**。

## 数据与安全

- 插件配置、同步状态与日志位于 `<DSH_HOME>/account-sync/`；除同步的文件本身外不写工作区。
- WebDAV 密码与 LAN 令牌保存在 DSH 凭据库（记录名 `account-sync-webdav`、`account-sync-lan`、`account-sync-lan-host`），HTTP API 永不返回。
- 发布前剥离机密设置：设置值用 `redactSecrets: true` 读取；`cordis.patch.yml` 覆盖项中任何形似 token/password/secret 的键也会被移除。
- 官方 `@deepseek-ai/*` bundle 不会被安装；只有开启了"安装缺失插件"时才会安装缺失的非官方 bundle。
- 工作区文件默认关闭，开启后默认同步所有已注册工作区（可只选部分）。默认忽略 `node_modules`、`.git`、虚拟环境、缓存、`dist`、`build`、冲突副本与临时文件，可追加自定义 glob。
- 会话记录同步**所有已注册工作区**，与"工作区文件"开关无关：即使只同步会话也能交换历史；本地已存在的日志永不覆盖。
- 传输数据以明文存放在你选择的文件夹/仓库中，加密与访问控制取决于该通道（网盘权限、Git 远端鉴权、WebDAV 凭据、LAN 令牌）；插件发布前会剥离机密，但不会对应用设置与工作区文件额外加密。
- 本地路径 bundle（`link:` 或绝对目录）只能在存在该路径的机器上安装；registry bundle 按名称安装。单个安装失败会记入报告，不会中断整次同步。
- 同步串行执行：正在同步时再次请求会返回 HTTP 409 `{busy:true}`。

## 常见问题

- **提示未配置**：所选传输方式还缺地址/路径。
- **Git 报错**：插件通过宿主 subprocess 调用 git，找不到时会回退到 `C:\Program Files\Git\cmd\git.exe`；请先在普通终端确认 `git ls-remote <远端>` 可用。
- **局域网测试失败**：可能是 Windows 防火墙拦截，请允许 DSH/node 访问专用网络，或更换端口。
- **没有可拉取的内容**：对端必须先成功发布过一次（在对端点"立即同步"）。
- **账号不同**：`userId` 与本机账号不同的对端只会列出，不会被应用。

## 开发

宿主：`index.js`、`lib/*.js`（纯 Node ESM，`node --check` 通过）。网页：`client.js`（`window.__ModuleLoader__.load` 的纯浏览器脚本，无打包器）。接口契约见 [CONTRACT.md](CONTRACT.md)。版本 0.1.0。
